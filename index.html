Video Automation API

Render personalized videos at scale

Wideo Automation API lets you render thousands of personalized videos programmatically. Perfect for dynamic creative, branded video personalization, high-volume ad production, and white-label solutions. The API follows an asynchronous batch model — submit a batch, get a batchId, and receive results via webhook.

How It Works

Asynchronous processing designed for compute-heavy rendering.

The API uses an asynchronous batch processing model because video rendering is compute-heavy. You send a list of videos, we return a batchId immediately, and we notify your webhook when processing finishes.

Step 1

POST /batch – enqueue a rendering job.

Step 2

batchId – unique identifier for the batch.

Step 3

Webhook – receives final result (success or failure).

Step 4

GET /batch/{batchId} – manual status check.

Core Endpoints

Structured cards with request/response examples.

Headers

Authentication

All API requests must include your API key in the request header. Obtain your key from the Wideo dashboard or by using the form below.

Request headerx-api-key
{
  "headers": {
    "x-api-key": "12345678-1234-1234-1234-123456789012"
  }
}

Each API key maps to a specific user account. Write operations are restricted to subfolders of your user folder inside the Wideo result bucket.

Enqueue an Automation Batch

POST /batch – submits a rendering job.

Request bodyJSON
{
  "templateId": "abcdefgh1234567890",
  "webhook": "https://your-server.com/webhook",

    {
      "title": "Tech Company - Keep Your Business Connected",

  ]

Immediate Response201 Created
{ "batchId": 1234567890 }
GET /batch/{batchId}

Get Batch Status

ResponseSUCCEEDED
{
  "batchId": 1234567890,
  "status": "SUCCEEDED",
  "videos": [
    {
      "videoUrl": "https://s3.../video.mp4?presigned...",
      "previewUrl": "https://s3.../preview.png?presigned..."
    }
  ]
}

Status values: SUCCEEDED, FAILED, RUNNING, TIMED_OUT, ABORTED.

Webhook

Asynchronous Webhook

When processing finishes, Wideo will POST to your provided webhook URL.

Success payloadPOST
{
  "batchId": 1234567890,
  "status": "SUCCEEDED",
  "videos": [...]
}
Failure payloadPOST
{
  "batchId": 1234567890,
  "success": "FAILED",
  "error": "Error while rendering videos, contact support"
}

Security & Data

Operational essentials for production integration.

Data lifecycle

Generated MP4 and PNG files are stored for 72 hours for troubleshooting. Presigned URLs remain accessible for 24 hours.

Encryption

All API traffic is encrypted with TLS (HTTPS). Rendered files are stored in AWS S3 with AES-256 encryption at rest.

Rate & concurrency limits

Rate & Concurrency Limits: Global limits protect our rendering infrastructure. Limits apply to all customers to ensure platform stability.
